いびきを記録できる Sleep Cycle の代替アプリ：8本を比較

著者 Menelik Tucker · 更新日 2026年9月28日

結論

Sleep Cycle をやめてもいびきの記録は続けたいなら、選択肢は Snore Timeline、Pillow、ShutEye、BetterSleep、SnoreLab、Snollo、AutoSleep、そして Android の Sleep as Android です。Snore Timeline は夜全体を録音していびきを検出し、浅い睡眠で起こすスマート起床アラームも備えています。サブスクリプションもアプリ内購入もなく、プライバシーラベルは Data Not Collected（日本の App Store では「データの収集なし」）です。Sleep Cycle のヘルプセンターは、いびきの検出を Premium に入れています。AutoSleep も Data Not Collected と申告しており、買い切り $8.99 ですが、Apple Watch が必要です。ほかの iPhone アプリ5本は、アプリ内購入で Premium を販売しています。

要点

  • Sleep Cycle は米国の App Store で 3万件の評価、星4.7 です。同社のウェブサイトによると、スマートアラームは無料プランで使えます。
  • 2026年9月27日の App Store での申告では、Sleep Cycle のラベルは Identifiers を Data Used to Track You（ユーザのトラッキングに使用されるデータ）に、7つのカテゴリを Data Linked to You（ユーザに関連付けられたデータ）に挙げています。
  • この一覧で Data Not Collected のラベルが付いているのは Snore Timeline と AutoSleep の2本です。AutoSleep は $8.99 で、Apple Watch が必要です。
  • Pillow、ShutEye、BetterSleep、AutoSleep、Sleep as Android は、いずれも浅い睡眠で起こすスマートアラームを備えていると説明しています。Snore Timeline のスマート起床アラームは、15分、30分、45分の時間枠の中でそれを行います。SnoreLab と Snollo にはありません。
  • Sleep Cycle のヘルプセンターは、いびきの検出、音の検出、睡眠メモを Premium 機能として挙げています。Snore Timeline では、いびきの検出、夜全体の音声、エクスポート、睡眠要因に料金はかかりません。
  • SnoreLab はいびきに特化したアプリです。Snore Score、対策の検証、5.7万件の評価がありますが、スマートアラームはなく、Premium は $5.99〜$59.99 です。

    Sleep Cycle の優れている点

    Sleep Cycle が支持されてきたのには理由があります。App Store の掲載情報にはエディターのおすすめのバッジがあり、評価は 3万件で星4.7、開発元はダウンロード数を4,000万回超としています。いちばん知られている機能はスマートアラームです。掲載情報によると、いちばん浅い睡眠フェーズのときに起こし、Sleep Cycle のスマートアラームのページによると、時間枠は10〜30分で設定します。同じページには "The Smart Alarm is available on our Free plan."（スマートアラームは無料プランで使えます）と書かれています。

    アプリは音またはスマートフォンの加速度センサーで睡眠を記録するので、ウェアラブルは必要ありません。掲載情報によると、いびき、咳、寝言を検出し、物語、サウンドスケープ、ガイド付き瞑想の睡眠用サウンドのライブラリも付いています。Who's Snoring? 機能は機械学習を使い、寝室を共有していても自分のいびきとパートナーのいびきを区別します。同社サイトは、これがほかのいびきアプリとの違いだとしています。まず目覚まし時計が欲しく、睡眠トラッカーは二の次なら、Sleep Cycle で足ります。

    米国 App Store の最新レビュー50件（2026年8月26日〜9月25日）で最も多い称賛は、睡眠データ（9件）とアラーム（7件）です。2026年9月23日のレビューには “No more stopping the alarm and falling back asleep.”（アラームを止めて二度寝することがなくなった）とあります。最も多い不満はサブスクリプション、トライアル、その解約（17件）で、そのうち7件は解約できなかった、または解約したのに課金されたとしています。記録の精度への不満（8件）も続きます。

    ほかを探す理由

    価格

    ダウンロードは無料です。掲載情報のアプリ内購入は $2.99〜$57.99 で、そのほとんどに Premium という名前が付いており、すべての機能を解除する $39.99 の項目もあります。ヘルプセンターの Premium 機能の一覧には、いびきの検出、音の検出、Who's Snoring?、睡眠メモ、心拍数の記録、オンラインバックアップ、すべての統計が含まれます [15]。

    プライバシーラベル

    Sleep Cycle のラベルは Identifiers を Data Used to Track You に挙げています。Apple の定義では、アプリのデータをターゲティング広告や広告効果の測定のためにほかの会社のデータとリンクすること、またはデータブローカーと共有することがトラッキングにあたります。Data Linked to You には7つのカテゴリ（Health & Fitness、Purchases、Location、Contact Info、Identifiers、Usage Data、Diagnostics）があり、いずれも開発元自身による申告です。Sleep Cycle のプライバシーポリシーによると、健康データは初期設定ではデバイスにとどまります。バックアップをオンにすると、アプリ内のすべてのデータが Google Cloud 上の同社のサーバーに送られ、同意を取り消すまで、またはサブスクリプション終了後最長1年間保存されます。同意すれば、仮名化した健康データをアプリの改善に使って最長3年間保持し、集計したデータや匿名化したデータをパートナーと共有したり公開レポートに使ったりできます [20]。

    いびきの検出と Premium

    Sleep Cycle のヘルプセンターは、いびきの検出と音の検出を、Who's Snoring? とともに Premium 機能として挙げています [15]。無料プランにはスマートアラーム、睡眠分析、毎晩の睡眠グラフが残ります。ヘルプセンターによると、保存した録音はまとめて書き出せず、1件ずつ共有することになります [16]。Snore Timeline では、いびきの検出、夜全体の音声、エクスポートが無料です。2つのアプリの比較はSnore Timeline と Sleep Cycle の比較をご覧ください。

    1. Snore Timeline

    Snore Timeline は私のアプリです。iPhone のマイク、AirPods、またはその他の Bluetooth マイクで夜全体を録音し、いびき、あえぎ、咳、寝言をすべてズーム可能なタイムラインに載せます。いびきはエピソードにまとまり、各エピソードには長さ、回数、ピークと平均の dB、わかりやすい言葉の要約が表示されます。どの瞬間もタップすれば聞けます。音声から拾った呼吸の一時停止には印が付き、医師に見せる材料にできます。ルールは検出の仕組みで説明しています。睡眠ステージ（覚醒、浅い、深い、レム）は音声だけから推定し、いびきのグラフの下に帯として表示します。グラフは音量と1分あたりのいびきで切り替えられるので、いびきが浅い睡眠、深い睡眠、レム睡眠のどこに集中しているかがわかります。

    スマート起床アラームは、自分で選んだ時間枠の中で浅い睡眠のときに鳴ります。詳しくは後述します。いびきをかくと、いびきナッジがサウンド、手首のタップ、またはその両方で知らせ、ナッジが効かないたびに1段階強くなります。エクスポートは CSV と音声で「ファイル」App に保存されます。各夜には0〜100の睡眠スコアが付き、いびきと呼吸の乱れもその要因に含まれます。アルコールや鼻腔拡張テープなど23の組み込みの睡眠要因、または自分で作った要因で夜にタグを付けられます。記録した夜が5夜になり、タグ付きが2夜以上、タグなしが2夜以上そろうと、アプリが両者を比べて効果のあったものを順位付けします。付属の Apple Watch アプリは、録音中の心拍数と HRV をリアルタイムで表示し、いびきナッジと無音のアラームで手首をタップし、録音を止めることもできます。録音を始めるのは iPhone です。ヘルスケアを通じて、Apple Watch、Oura、Whoop、Garmin、Ultrahuman のデータが睡眠スコア、回復度、ハイプノグラムに反映されます。1晩に複数のソースのステージがある場合は、ソースごとに別のタイムラインになるので比べられます。

    料金は無料で、サブスクリプションもアプリ内購入もありません。ラベルは Data Not Collected と申告しています。評価は214件で星4.9 と、Sleep Cycle の 3万件に比べると少なめです。Snore Timeline が App Store に登場したのは2025年9月、Sleep Cycle は2009年で、私は外部資金もマーケティング予算もなく、ひとりで開発しています。

    フィードにあった Snore Timeline の米国 App Store のレビューは38件（2025年11月14日〜2026年9月19日）で、最も多い称賛はサブスクリプションや有料機能の制限がないこと（23件）、次が使いやすさ（11件）です。唯一の星3のレビューは、パートナーの CPAP のホースの音がいびきと誤って検出され、それを削除できなかったというものです。その数日後のアップデートで、エピソードを削除できるようになりました。

    こんな人に：Sleep Cycle のようなスマートアラームに加えて、無料のいびき検出、聞き直して書き出せる夜全体の音声、いびきをかいたときのナッジが欲しい人。すべてサブスクリプションなしで、ラベルは Data Not Collected です。

    2. Pillow

    Apple Watch を使うなら Pillow です。App Store の掲載情報によると、Apple Watch、iPhone、iPad で睡眠サイクルを分析し、スマートアラームはできるだけ浅い睡眠ステージで起こすことを目指します。心拍数の分析とステージの図があり、デバイス上の機械学習でいびきと寝言を録音しますが、Smart Wake-up、音声録音、心拍数の分析、CSV エクスポートはすべて Premium の一覧に入っています。Pillow 自身のガイドによると、ウォッチを着けるだけの Automatic Mode では、アラームを鳴らすことも、いびきを検出することもできません [14]。Snore Timeline のスマート起床アラームと録音は無料です。Pillow にはエディターのおすすめのバッジがあります。

    料金体系：サブスクリプション。月額 $19.99、年額 $49.99、3か月 $59.99。ラベル：Data Used to Track You の申告なし。Data Linked to You には Identifiers、Usage Data、Diagnostics。評価：9.6万件で星4.4。

    米国 App Store の最新レビュー50件（2026年7月20日〜9月25日）で最も多い称賛は、睡眠のパターンを理解する助けになること（12件）で、最も多い不満は、アプリを開くとサブスクリプションのトライアル画面になり、無料版に入る方法がないこと（17件）です。7件は睡眠トラッキングの精度を疑問視しています。

    こんな人に：同社サイトの説明どおり、iPhone なしで Apple Watch だけで睡眠を記録したい人。詳しくはSnore Timeline と Pillow の比較で。

    3. ShutEye

    ShutEye が前面に出すのは音です。App Store の掲載情報には、睡眠用サウンドと環境音のライブラリ、寝る前の物語、カスタムのサウンドミックス、いびきを記録する睡眠トラッカーが挙げられており、やさしく起こすためのスマートアラームもあります。FAQ によると、このアラームはいちばん浅い睡眠フェーズのときに起こします。Apple Watch アプリはなく、ウォッチのデータはヘルスケア経由で読み込みます。評価は 35万件で、この一覧でも最多クラスです。

    サブスクリプションです。掲載情報では年額 $59.99 とされ、アプリ内購入は $9.99〜$69.99 です。ラベルでは、Identifiers が Data Used to Track You と Data Linked to You の両方に挙がり、Health & Fitness はリンクされないデータとして申告されています。プライバシーポリシーによると、健康データを広告パートナーと共有することはなく、商品のおすすめを受ける共同プログラムにオプトインすると、睡眠データが IKEA に送られます [21]。評価は 35万件で星4.8 です。

    米国 App Store の最新レビュー50件（2026年6月30日〜9月24日）で最も多い不満は、トライアルの課金と有料機能の制限（19件）と、本人は起きていたと言うのに睡眠トラッキングが眠っていたと記録すること（11件）です。称賛はばらけています。5件は睡眠の助けになったとしていますが、5回以上言及された特定の機能はありません。

    こんな人に：いびきをかいたタイミングを知ることと同じくらい、音を聞きながら寝付くことが大事な人。Snore Timeline と ShutEye の比較をご覧ください。

    4. BetterSleep

    BetterSleep は Relax Melodies として始まりました。App Store の掲載情報によると、睡眠用サウンドと音楽が300以上、瞑想が250以上、睡眠用の物語が100以上あります。睡眠レコーダーは、いびき、寝返り、寝言、そのほか夜によくある音のタイミングを聞き分けます。就寝リマインダーとタイマーもあります。ヘルプセンターでは、設定した時間枠の中で浅い睡眠のときに起こすスマートアラームを説明しています。Snore Timeline のスマート起床アラームと同じ考え方です。評価は 39.1万件で、この一覧の App Store のアプリの中で最多です。

    料金体系：サブスクリプション。アプリ内購入は $11.99〜$99.99。ラベル：Data Used to Track You に Purchases、Identifiers、Usage Data、Other Data。Data Linked to You には7つのカテゴリ。評価：39.1万件で星4.7。

    米国 App Store の最新レビュー50件（2026年8月26日〜9月26日）で最も多い称賛は、寝付きと眠りの維持の助けになること（8件）と、カスタムのサウンドミックス（5件）です。33件は価格に不満を述べ、そのうち22件は、無料で使っていたサウンドにサブスクリプションが必要になったとしています。

    こんな人に：サウンド、物語、瞑想の大きなライブラリが第一で、サブスクリプションに登録するつもりがあり、いびきの確認は二の次という人。

    5. SnoreLab

    SnoreLab はいびきに特化したアプリです。App Store の掲載情報には、いびきの検出、強さを表す Snore Score、夜全体の録音（FAQ によると Premium）、BreathFlow による呼吸の分析、そして何がいびきを変えるかを確かめる対策と生活習慣の記録が挙げられており、録音はメールで共有できます。SnoreLab は医療機器ではないとはっきり書かれています。SnoreLab にはスマートアラームがありません。アラームは設定した時刻にセッションを終えるもので [11]、FAQ はスマートアラームが欲しい人に姉妹アプリの Sleepwave を案内しています [12]。いびきアラームもなく [18]、Apple Watch アプリもありません。評価の 5.7万件は、ここに挙げたいびき専用アプリの中で最多です。

    Premium は $5.99〜$59.99 のアプリ内購入で販売され、サブスクリプションと $7.99 の買い切りがあります。ラベルは、Usage Data を Data Used to Track You に、Health & Fitness、Contact Info、User Content、Identifiers を Data Linked to You に挙げています。2026年9月18日に更新されたプライバシーポリシーによると、記録するたびに呼吸数、呼吸の乱れ、睡眠ステージなどの睡眠データを収集し、統計の表示、同意した場合のコンテンツの調整、そして集計したうえでのアプリの改善に使います。ヘルスケアのデータが SnoreLab に渡るのは、研究にオプトインした場合だけです [19]。評価は 5.7万件で星4.7 です。

    米国 App Store の最新レビュー50件（2026年4月24日〜9月26日）で最も多い称賛は、いびきを減らす方法を見つける助けになったこと（10件）と、すでにわかっている睡眠時無呼吸や CPAP の様子を見るのに使っていること（9件）です。最も多い不満は、価格、トライアル、有料機能の制限（9件）と、録音できなかった夜やクラッシュ（8件）です。

    こんな人に：ほかのユーザーと比べられる Snore Score（FAQ に説明があります）と、読み物のある対策ライブラリが欲しい人。Snore Timeline の答えは、いびきを要因の1つとする0〜100の睡眠スコアと、効果のあったものを順位付けする23の組み込み睡眠要因です。Snore Timeline と SnoreLab の比較で2つを比べています。

    6. Snollo

    Snollo はいびきの録音と Apple Watch のデータを組み合わせています。App Store の掲載情報によると、ウォッチから心拍数、呼吸数、血中酸素を読み取り、睡眠ステージと睡眠スコアを表示し、音響分析は iPhone 上で行います。FAQ によると、ウォッチがない場合は、スマートフォンをベッドに置き、iPhone のマイクとモーションセンサーからステージを得ます。掲載情報では、録音と健康の記録はあなた専用の iCloud コンテナに保存されます。雨、自然音、ホワイトノイズのサウンドも付いています。Sleep Cycle との比較ページによると、Snollo にはスマートアラームがありません [17]。新しいアプリでもあり、評価は14件なので、平均の2.9はわずかな声に基づくものです。

    サブスクリプションは週額 $13.99、月額 $5.99、年額 $39.99 です。ラベルは Data Used to Track You に何も申告していませんが、Data Linked to You には Health & Fitness、Purchases、Location、Contact Info、User Content、Identifiers が入っています。プライバシーポリシーによると、睡眠データと音声クリップはあなた専用の iCloud に保存され、分析ツールが受け取るのはあなたの User ID とアプリ内のイベントだけで、睡眠データ、音声、健康情報は含まれません [22]。評価は14件で星2.9 です。

    フィードから返ってきた米国 App Store のレビューは9件だけでした（2026年3月11日〜9月17日）。そのうち5件は、何も録音されなかった、または分析中のまま止まったとしています。5件に届く称賛の傾向はありません。

    こんな人に：睡眠用サウンドのライブラリが欲しく、記録を iCloud で Apple デバイス間で同期したい人。新しいアプリでも気にならない人向けです。

    7. AutoSleep

    Tantsissa の AutoSleep は Apple Watch が主役です。App Store の掲載情報によると、ボタン操作なしで Apple Watch から睡眠を記録し、watchOS 4 以降が必要です。睡眠リング、心拍数、血中酸素、呼吸数、手首の温度、そして浅い睡眠で目覚めやすくするウォッチ内蔵のスマートアラームが挙げられています。いびきの強さは別アプリの AutoSnore で記録します。掲載情報には、2018年から2023年までの Best of App Store への選出が記されています。

    料金体系：買い切り $8.99。掲載情報には、追加のアプリ内購入もサブスクリプションもないと明記されています。ラベル：申告内容は Data Not Collected。評価：6.2万件で星4.7。

    米国 App Store の最新レビュー50件（2026年9月7日〜25日）で最も多い称賛は、睡眠習慣を変えるきっかけになった気づき（15件）と正確さ（7件）で、最も多い不満は、最近のアップデート以降の記録の抜けや誤り（9件）です。

    こんな人に：掲載情報のとおり、ウォッチだけで動く睡眠リングとスマートアラームが欲しい人。いびきのデータが必要なら、別売り $4.99 の AutoSnore を追加します。Snore Timeline はスマートフォンの音声からステージを推定するので、ウォッチがあってもなくても使え、Watch アプリで手首をタップして起こすこともできます。

    8. Sleep as Android（Android のみ）

    Android のスマートフォンなら、Petr Nálevka（Urbandroid）の Sleep as Android がアラームといびきの両方をカバーします。Google Play の掲載情報には、睡眠サイクルを記録し、最適なタイミングでやさしく起こすスマートアラームが挙げられています。いびき対策、寝言、体調不良の検出のための AI 音声認識、Sonar による非接触の記録、Wear OS、Garmin、Fitbit などのウェアラブルへの対応も挙げられています。エディターのおすすめのバッジがあり、ダウンロード数は1,000万回以上です。

    料金体系：7日間 Premium を試したあと、フリーミアムを続けるかアップグレードするかを選べます。掲載情報には広告とアプリ内購入の記載があります。データ セーフティ：Google Play では、位置情報、健康とフィットネス、ほか2種類を共有する可能性があり、位置情報、健康とフィットネス、ほか3種類を収集する可能性があると表示されています。評価：39.2万件のレビューで4.6。

    Sleep as Android は App Store に掲載されていないので、このページではレビューの要約を載せていません。

    こんな人に：Android を使っていて、Wear OS、Garmin、Fitbit のウォッチも連携させたい人。Snore Timeline の Android 版はウォッチに対応していません。Google Play のアプリです。ほかの選択肢はAndroid におすすめのいびきアプリにまとめています。

    スマートアラームを手放さない

    いちばん恋しくなるのはアラームかもしれません。この一覧のうち7本が、浅い瞬間を選んで起こすアラームを備えていると説明しています。Snore Timeline、Pillow、ShutEye、BetterSleep、AutoSleep、Sleep as Android、そして Sleep Cycle 自身です。Pillow は Smart Wake-up を Premium に入れています。AutoSleep のアラームは Apple Watch で動きます。SnoreLab と Snollo にはスマートアラームがありません [11] [17]。

    Snore Timeline のスマート起床アラームの仕組み

    設定の「起床」で起床時刻とアラーム音を決め、スマート起床アラームの時間帯を15分、30分、45分から選びます。その枠の中で、アプリはリアルタイムの睡眠ステージ推定と、体の動きや寝言などの音を見ています。寝返りを打ったり寝言を言ったりすると、すでに目覚めかけているとみなしてすぐにアラームが鳴ることがあります。浅い睡眠の判定だけの場合は、枠の後半でしか鳴りません。良い瞬間が来なければ、設定した時刻に鳴ります。音は最初の数秒でフェードインし、1回の操作でアラームとその夜の録音がまとめて止まります。

    スマート起床アラームを使うには、「睡眠インサイト」をオンにしておく必要があります。Apple Watch があれば、音の代わりに手首のタップで起きられるので、パートナーを起こしません。録音が夜中に止まった場合に備えて、アプリはバックアップのシステムアラームも予約します。各設定はスマート起床アラームのサポートページで、手首側のことはApple Watch・バイオメトリクス・ヘルスケアで説明しています。

    医療に関する注意

    Snore Timeline は音声を分析します。医療機器ではなく、睡眠時無呼吸症候群やその他の疾患を診断するものでもありません。呼吸の一時停止が疑われる場合は、録音を医師に見せてください。

    よくある質問

    Sleep Cycle の無料の代替アプリはありますか？

    Snore Timeline は無料で、サブスクリプションもアプリ内購入もなく、スマート起床アラームといびきの検出を備えています。Android では、Sleep as Android が7日間の Premium のあと、広告付きのフリーミアムになります。

    Pillow、ShutEye、BetterSleep、SnoreLab、Snollo はダウンロード無料で、アプリ内購入で Premium を販売しています。

    サブスクリプションのない Sleep Cycle の代替アプリはどれですか？

    Snore Timeline にはサブスクリプションも購入項目も一切ありません。AutoSleep は最初に $8.99 かかり、掲載情報にはアプリ内購入もサブスクリプションもないとありますが、Apple Watch が必要です。この一覧のほかのアプリはサブスクリプションを販売しています。

    Sleep Cycle は無料でいびきを検出できますか？

    いいえ。Sleep Cycle のヘルプセンターは、いびきの検出、音の検出、Who's Snoring?（自分のいびきとパートナーのいびきを分ける機能）を Premium 機能として挙げています。

    無料プランには、スマートアラーム、睡眠分析、毎晩の睡眠グラフが含まれます。Snore Timeline は、サブスクリプションもアプリ内購入もなしで、無料でいびきを検出します。

    収集するデータがいちばん少ない代替アプリはどれですか？

    2026年9月27日の申告では、この一覧で App Store に Data Not Collected と申告しているのは Snore Timeline と AutoSleep の2本です。Snore Timeline は無料で購入項目もなく、AutoSleep は $8.99 で Apple Watch が必要です。

    これらのラベルは開発元が自分で記入するもので、App Store には Apple が検証していないと注記されています。プライバシーラベルの比較では、いびき・睡眠アプリ14本を並べています。

    これらのアプリは Apple Watch なしで使えますか？

    1本を除いて使えます。AutoSleep には Apple Watch が必要です。Snore Timeline、Sleep Cycle、SnoreLab、ShutEye、BetterSleep はスマートフォンのマイクで録音します。Pillow の掲載情報には、Apple Watch、iPhone、iPad で使えるとあります。Snollo は Apple Watch のデータを中心に作られています。

    Snore Timeline は音声だけから睡眠ステージを推定し、ウォッチを着けていれば心拍数、血中酸素などの値も加えます。
