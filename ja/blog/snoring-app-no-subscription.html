サブスクリプション不要のいびきアプリ：14本を費用順に整理

著者 Menelik Tucker · 更新日 2026年9月28日

結論

私が確認したいびき・睡眠アプリ14本のうち、買うものが何もないのは Snore Timeline と Snore Recorder - Sleep Monitor の2本です。AutoSnore（$4.99）と SnoreClock（$9.99）はダウンロード時に一度だけ支払い、アプリ内では何も販売していません。残りの10本はアプリ内購入としてサブスクリプションのプランを販売しています。14本のうち、購入項目がまったくなく、プライバシーラベルが Data Not Collected（データの収集なし）なのは Snore Timeline だけです。無料のダウンロードに、ほかのアプリが販売している機能が含まれています。夜全体の音声とエクスポート、ウェアラブルなしで録音から推定する睡眠ステージ、睡眠スコア、対策の記録、いびきナッジ、スマート起床アラームです。

要点

  • Snore Timeline と Snore Recorder - Sleep Monitor は、App Store に価格もアプリ内購入も掲載していません。
  • AutoSnore は $4.99、SnoreClock は $9.99 で、どちらもアプリ内購入がなく、ラベルは Data Not Collected です。
  • SnoreLab の掲載情報には「SnoreLab Premium One-time Purchase」（SnoreLab Premium 買い切り）という $7.99 の項目がありますが、何が使えるようになり、それがいつまでなのかは、掲載情報にも SnoreLab の FAQ にも書かれていません。
  • Snore Control は月額と年額のプランと並べて “Full Version”（フルバージョン）を $31.99 で掲載していますが、この $31.99 の項目の期間は掲載情報に書かれていません。
  • 14本のうち4本が Data Not Collected と申告しており、そのうちサブスクリプションを販売しているのは Somnio+ です。
  • ほかのアプリではサブスクリプションの対象になっている機能が、Snore Timeline では無料です。各社のヘルプページによると、SnoreLab は夜全体の録音とエクスポートに、Pillow は音声録音、CSV エクスポート、スマートウェイクに料金がかかります。
  • App Store のサブスクリプションは、「設定」で自分の名前をタップし、「サブスクリプション」から解約します。

    Snore Timeline

    Snore Timeline は私が開発しています。サブスクリプションもアプリ内購入も、アカウントもサーバーもありません。すべての機能をすべてのユーザーが無料で使えます。スマートフォンのマイク、AirPods、またはその他の Bluetooth マイクで夜全体を録音し、いびき、あえぎ、咳、寝言、呼吸をその場で聞き分けます。いびきはエピソードにまとめられ、30秒の間隔があるとエピソードが終わります。各エピソードには、長さ、いびきの回数、ピークと平均の音量、リズム、わかりやすい言葉での要約が表示されます。

    呼吸音が1分以上聞こえたあとに10秒以上の無音が続き、大きないびき、あえぎ、呼吸などの回復音がその無音を破ると、アプリは呼吸の乱れとして印を付けます。睡眠ステージ（覚醒、浅い、深い、レム）は録音だけから推定するので、ウェアラブルもヘルスケアも必要ありません。夜間サマリーでは、音量と1分あたりのいびきで切り替えられるいびきのグラフの下に睡眠ステージの帯が表示され、いびきが浅い睡眠、深い睡眠、レム睡眠のどこに集中しているかがわかります。各夜には0〜100の睡眠スコアが付き、いびきと呼吸の乱れは減点になります。CPAP や鼻腔拡張テープなどあらかじめ用意された23の睡眠要因、または自分で作った要因で夜にタグを付けられ、記録した夜が5夜になり、タグ付きが2夜以上、タグなしが2夜以上そろうと、アプリが効果のあったものを順位付けします。

    いびきナッジは、いびきをかくとサウンドを鳴らすか、Apple Watch で手首をタップするか、その両方で知らせ、ナッジが効かないたびに1段階強くなります。スマート起床アラームは、15分、30分、45分から選んだ枠の中で眠りの浅いときに起こします。Apple Watch アプリは心拍数と HRV をリアルタイムで表示し、録音を止めることもできます。Apple Watch、Oura、Garmin、Whoop、Ultrahuman のステージのデータはヘルスケアを通じて取り込まれ、ソースごとに別のタイムラインになります。CSV ファイル、音声クリップ、夜全体の音声は、すべて「ファイル」App に書き出せます。Android 版もあります。

    Apirox の Snore Control は、AI でいびきを検出して録音し、いびきが2回続くといびき停止機能を作動させます。ヘルスケアに書き込み、評価は608件で星4.4 です。Smart Alarms を $3.99 の追加機能として販売していますが、Snore Timeline ではスマート起床アラームもいびきナッジも無料のダウンロードに含まれています。掲載情報には自動更新に関するサブスクリプション情報の欄があります。購入項目は Full Version - Monthly（$4.99）、Full Version - Yearly（$15.99）、Full Version（$31.99）、Smart Alarms（$3.99）、Sleepy Sounds（$3.99）、Themes（$0.99）です。$31.99 の “Full Version” は名前に期間がなく、掲載情報にも期間は書かれていません。apirox.com の Snore Control のページも確認しましたが、機能の説明だけで価格は載っていません。そのため、$31.99 の項目が永続的なものかどうかは確認できませんでした。

    Somnio+

    Somnio+（掲載名は Sleep Apnea Detector - Somnio+）は、睡眠中の音を録音し、いびき、寝言、長い無音を呼吸の一時停止の可能性として印を付けます。掲載情報には、医療機器ではなく、診断を提供するものでもないと明記されています。Data Not Collected と申告しています。評価は16件で星3.8 です。掲載されている購入項目：Sleep Apnea Detector - Weekly（$9.99）、Weekly Special（$4.99）、Sleep Apnea Detector - Annual（$29.99）、Annual Special（$14.99）。

    機能別に整理したいびきトラッカーは、SnoreLab の代替アプリとiPhone 向け無料いびきアプリをご覧ください。

    サブスクリプションで何にお金を払うのか

    Apple の App Review ガイドライン（3.1.2項）は、自動更新サブスクリプションに対して、顧客に “ongoing value”（継続的な価値）を提供することを求めています。Apple が挙げる例には、継続的で実質的なアップデートがあるアプリ、大規模または更新されるメディアコレクション、SaaS、クラウドのサポートがあります。睡眠アプリで継続的にかかる費用は、サーバーとアカウントです。サウンドライブラリにはライセンス料と新しいコンテンツの費用も加わります。

    ShutEye と BetterSleep はそれぞれ豊富なサウンドライブラリを備え、SnoreLab は音声のバックアップを提供しています。

    Snore Timeline にはそうした費用がありません。サーバーも、アカウントも、ライセンスが必要なサウンドライブラリもありません。録音、検出、保存はスマートフォン上で行われるので、ユーザーが増えても運用費は増えません。デバイス上で何が動いているかは検出の仕組みで説明しています。

    支払う前に確認すること

    トライアルの条件

    トライアルは、解約しない限り有料プランに切り替わります。サブスクリプションの解約についての Apple のサポートページには、更新したくない場合はトライアル終了の24時間以上前に解約するよう書かれています。トライアルを始めた日にリマインダーを設定し、トライアル期間の夜を使って、欲しい音声をアプリが残してくれるかを確かめてください。最初の夜のスマートフォンの置き方ははじめにで説明しています。上のアプリのうち、SnoreLab（FAQ による）、Koala Nap、SleepScore は7日間のトライアルを明記しており、Sleep Cycle は掲載情報に期間なしで無料トライアルを載せています。

    プライバシーラベルの Purchases の行

    Sleep Cycle、SleepScore、Snollo は、Purchases を Data Linked to You（ユーザに関連付けられたデータ）として申告しています。BetterSleep は Purchases をユーザに関連付けられたデータとして、さらに Data Used to Track You（ユーザのトラッキングに使用されるデータ）としても申告しています。Pillow は Purchases をユーザに関連付けられないデータとして申告しています。この行からわかるのは、2026年9月27日の申告どおり、開発元があなたの購入履歴を収集すると申告したことです。Data Not Collected の4本は、Purchases を含めて何も申告していません。

    解約の方法

    iPhone で「設定」を開き、自分の名前をタップし、「サブスクリプション」をタップしてプランを選び、「サブスクリプションをキャンセルする」をタップします。Apple のページによると、キャンセルのボタンがない場合や、赤字で有効期限のメッセージが表示されている場合は、そのサブスクリプションはすでに解約されています。

    医療に関する注意

    Snore Timeline は音声を分析します。医療機器ではなく、睡眠時無呼吸症候群やその他の疾患を診断するものでもありません。呼吸の一時停止が疑われる場合は、録音を医師に見せてください。

    よくある質問

    サブスクリプションのないいびきアプリはどれですか？

    2026年9月27日に米国の App Store で確認したいびき・睡眠アプリ14本のうち、サブスクリプションを販売していないのは4本です。Snore Timeline と Snore Recorder - Sleep Monitor は価格もアプリ内購入もありません。AutoSnore（$4.99）と SnoreClock（$9.99）はダウンロード時に一度だけ料金がかかり、アプリ内購入を掲載していません。

    Snore Timeline はずっと無料ですか？

    このページの冒頭に示した日付の時点で、Snore Timeline にはサブスクリプションもアプリ内購入もありません。すべての機能をすべてのユーザーが使え、費用のかかるアカウントやサーバーもありません。

    何年も先のアプリの価格を約束できる開発者はいません。Snore Timeline を誰が作っているのか、これらのガイドにどう日付を付けて再確認しているのかは、概要ページで説明しています。

    SnoreLab に買い切りのプランはありますか？

    SnoreLab の米国 App Store の掲載情報には、“SnoreLab Premium One-time Purchase” という $7.99 のアプリ内購入と、名前に期間のない “SnoreLab Premium” という $5.99 と $17.99 の2項目があります。これらのどれかで永続的に使えるとは、掲載情報にも snorelab.com の FAQ にも書かれていません。

    SnoreLab の FAQ は、価格はアプリ内のアップグレード画面で確認するよう案内しています。掲載情報自体の説明文には、期間終了の24時間以上前に自動更新をオフにしない限り更新されるサブスクリプションと書かれています。

    買い切りのアプリはデータを収集しますか？

    ラベルによれば、収集していません。AutoSnore と SnoreClock はどちらも App Store で Data Not Collected と申告しており、ラベルは各開発元自身による申告です。

    支払い方式でラベルが決まるわけではありません。Somnio+ はサブスクリプションを販売していて、Data Not Collected と申告しています。Snore Recorder - Sleep Monitor は何も販売しておらず、User Content と Usage Data をユーザに関連付けられないデータとして申告しています。

    いびきアプリのサブスクリプションはどう解約しますか？

    iPhone で「設定」を開き、自分の名前をタップし、「サブスクリプション」をタップしてサブスクリプションを選び、「サブスクリプションをキャンセルする」をタップします。Apple のサポートページによると、トライアルを始めて更新したくない場合は、トライアル終了の24時間以上前に解約する必要があります。
