Snore Timeline と Sleep Cycle：いびき、アラーム、プライバシーを比較

睡眠トラッキング付きのスマートアラームと、一晩中録音するいびきレコーダー。それぞれが何を記録し、何に課金し、何を収集するかを、2026年9月27日に両アプリの公式ページで確認しました。

著者 Menelik Tucker · 更新日 2026年9月28日

結論

Sleep Cycle は、呼吸の音から睡眠ステージを推定するスマートアラーム兼睡眠トラッカーで、ヘルプセンターではいびきの検出、音の検出、睡眠メモを Premium としています。Snore Timeline は、購入するものが何もないいびきレコーダーです。夜全体を録音し、いびき、あえぎ、咳、寝言のクリップをすべてズーム可能なタイムラインに載せ、呼吸の一時停止に印を付け、いびきをかくとナッジで知らせ、眠りの浅いときに起こします。同じ録音から睡眠ステージを推定し、1つのグラフでいびきの下に表示します。Sleep Cycle の App Store のプライバシーラベルは、あなたのトラッキングに使用される Identifiers と、あなたにリンクされる7つのカテゴリを挙げており、Snore Timeline のラベルは Data Not Collected（データは収集されません）です。アラーム、睡眠用サウンド、コーチングが目当てなら Sleep Cycle を、お金を払わずにすべてのいびきを聞いてグラフで見たいなら Snore Timeline を選んでください。

要点

  • 価格：Snore Timeline にはサブスクリプションも App 内課金もありません。Sleep Cycle は App Store で Premium を $2.99〜$57.99 で販売しており、ヘルプセンターでは、いびきの検出、音の検出、Who's Snoring?、睡眠メモ、心拍数の記録が Premium です。
  • プライバシーラベルは異なります。Sleep Cycle のラベルは Identifiers を Data Used to Track You（あなたのトラッキングに使用されるデータ）に、Health & Fitness を含む7つのカテゴリを Data Linked to You（あなたにリンクされるデータ）に挙げています。Snore Timeline のラベルは Data Not Collected です。
  • どちらにも浅い睡眠を狙う無料のスマートアラームがあります。Sleep Cycle の時間枠は10〜30分、Snore Timeline のスマートアラームは15分、30分、45分から選べます。
  • どちらもウェアラブルなしで、スマートフォンのマイクから睡眠ステージを推定します。Snore Timeline はステージをいびきのグラフの下に表示し、Apple Watch、Oura、Garmin、Whoop、Ultrahuman のステージも Apple ヘルスを通じて取り込み、ソースごとに分けて残します。
  • 呼吸：どちらも音声をもとにしており、睡眠時無呼吸症候群を診断するものではありません。Snore Timeline は回復音で終わる10秒の無音に無料で印を付け、Sleep Cycle の呼吸の乱れのデータは Premium です。
  • AirPods やその他の Bluetooth マイクについては、Snore Timeline はそれで録音でき、Sleep Cycle のヘルプセンターは Bluetooth 機器の接続を切るよう案内しています。

    価格

    Snore Timeline には、サブスクリプションも App 内課金も有料プランもありません。この記事で紹介する機能は、すべて最初の夜から使えます。

    Sleep Cycle のダウンロードは無料です。App Store の掲載情報には Premium の App 内課金が10項目あり、米国のストアでの価格は $2.99〜$57.99 ですが、どの価格がどの請求期間に当たるかは書かれていません。機能紹介ページでは60日間のトライアルを提供しています。

    Sleep Cycle の無料プランでできること

    Sleep Cycle のヘルプセンターは、2026年6月に最終編集されたFreemium と Premium についての記事で2つのプランを分けています。無料プランに挙げられているのは、スマートアラーム、睡眠分析、毎晩の睡眠グラフ、一部のアラーム音、Sleep Goal、iOS での Apple ヘルスとの連携、Android での Health Connect、データベースのエクスポート、一部の Sleep Aid です。Premium には、いびきの検出、音の検出、Who's Snoring?、咳、睡眠メモ、iOS での呼吸数と心拍数の記録、オンラインバックアップ、週間レポート、Apple Watch の追加機能が入っています。

    App Store の掲載情報では書き方が違い、データのエクスポートと Apple ヘルスとの同期を Premium のツールに数えています。この2項目について Sleep Cycle の2つの情報源は食い違っているので、どちらかにお金を払う前にアプリ内で確認してください。

    プライバシー

    App Store のすべての掲載情報にはプライバシーラベルがあります。開発元は、アプリとそのパートナーが何を収集し、そのデータがあなたの身元にリンクされるかを申告します。Apple の App Privacy Details のページは、トラッキングを、アプリのデータをターゲティング広告や広告効果の測定のために第三者のデータとリンクすること、またはデータブローカーと共有することと定義しています。同じページには、回答を正確に保つ責任は開発元にあると書かれています。ラベルが示すのは開発元が収集すると言っている内容で、データの行き先ではありません。

    2026年9月27日の App Store での申告では、2つのラベルは次のとおりです。

    Sleep Cycle の掲載情報で「App のプライバシー」の見出しをタップすると、各カテゴリが項目と用途に分かれて表示されます。Developer's Advertising or Marketing には Coarse Location、Email Address、Name、User ID、Device ID が、Analytics には Health、Purchase History、Coarse Location、Email Address、Name、User ID、Product Interaction、Crash Data が挙げられています。Audio Data も User Content もないので、Sleep Cycle はあなたの録音を収集するとは申告していません。

    Sleep Cycle のプライバシー通知が睡眠データについて認めていること

    Sleep Cycle のプライバシー通知によると、健康データは初期設定ではデバイスにとどまり、あなたが同意しない限り会社はアクセスできません。同意すれば、通知はさらに次のことを認めています。

    • バックアップ。Premium 機能のオンラインバックアップは、アプリ内のすべてのデータを Google Cloud のサーバーに保存します。データは同意を取り消すかサブスクリプションを終えるまで、そして解約後最長1年間そこに残ります。
    • 製品開発。アプリの改善への協力を選ぶと、健康データはハッシュ化した ID のもとで仮名化され、Amplitude とそのホストである Amazon Web Services に送られます。同意を取り消すまで、または収集から最長3年間の、いずれか長いほうの期間保持されます。
    • 集計したインサイト。健康データを含む匿名化または集計したデータは、公開レポートに使われたり、契約のもとでパートナーに渡されたり、Premium ユーザーが見るコミュニティの基準値に使われたりします。同意を取り消しても、すでに収集したデータは統計や科学の目的で仮名化された形で残ることがあります。
    • 研究。研究に参加すると、Sleep Cycle はあなたの個人データを研究者と共有し、その後は研究者がデータを管理します。同意を取り消すと新たな共有は止まりますが、過去の転送は取り消されません。

    カスタマーサポートが問題の解決のために、同意を得て健康データを求めることもあり、問い合わせが終わると削除または匿名化します。Snore Timeline にはバックアップ先となるアカウントもサーバーもないので、録音はエクスポートするまでスマートフォンにとどまります。全体の状況は14本のラベル比較をご覧ください。

    スマートアラームどうしの比較

    Sleep Cycle はアラームで名を上げました。App Store のサブタイトルは目覚まし時計とトラッキングのアプリとしており、サイトにはスマートアラームは無料プランで使えるとあります。アプリは音または加速度センサーで睡眠を記録し、起床の時間枠の中で浅いステージのときに鳴ります。スマートアラームのページでは、その時間枠を10〜30分としています。Google Play では最大90分で、その掲載情報にはスマートフォンを振るかダブルタップしてスヌーズする機能も書かれています。スマートアラームのページによると、カスタムのアラーム音と、Apple Watch や Android のウォッチとの連携には Premium が必要です。

    Snore Timeline のスマートアラームは、同じことをいびきレコーダーの中で行います。時間枠を15分、30分、45分から選びます。アプリはリアルタイムの睡眠ステージ推定と、あなたの体動や音を見ていて、目覚めかけたときに鳴ります。浅い瞬間が来なければ、設定した時刻に鳴ります。アラームはフェードインし、1回の操作で音とその夜の録音がまとめて止まります。Apple Watch があれば手首のタップだけで起こせるので、パートナーは眠ったままでいられます。「睡眠インサイト」をオンにしておく必要があります。設定方法はスマートアラームのガイドで説明しています。

    アラームがアプリを求めるいちばんの理由なら、Sleep Cycle のほうがアラーム音の選択肢が多く、実績も長くあります。Snore Timeline のアラームが鳴るときには、その夜の録音、睡眠ステージ、いびきがすでにグラフになっています。

    いびきの記録の深さ

    Sleep Cycle の Nighttime Sounds のページには、アプリは "capture nighttime noises like snoring or sleep talking, and track trends over time."（いびきや寝言などの夜間の音を捉え、時間の経過に伴う傾向を記録する）ことができるとあります。いびきの頻度と強さを測り、Who's Snoring? 機能は、そのいびきがあなたのものかパートナーのものかを判別します。聞くのは翌朝です。ヘルプセンターによると、いびきの検出と音の検出は Premium です。

    Snore Timeline は、スマートフォンのマイク、または AirPods やその他の Bluetooth マイクで夜全体を録音します。すべての音をその場で分析し、一定間隔でのサンプリングはしません。いびき、あえぎ、咳、寝言、呼吸を拾い、いびきをエピソードにまとめます（30秒の間隔があくとエピソードが終わります）。各エピソードには、長さ、いびきの回数、ピークと平均の dB、リズムの分類、わかりやすい言葉の要約が表示されます。タイムラインは1秒単位の細部から1時間単位の全体までズームでき、どの位置をタップしても強調した音声を再生できます。まとめ方はエピソードとイベントで説明しています。

    Snore Timeline は、いびきが起きているその場で働きかけることもできます。いびきナッジは、いびきをかくとサウンドを鳴らすか、Apple Watch で手首をタップするか、その両方で知らせ、ナッジが効かないたびに1段階強くなります。

    カップルにとって、Who's Snoring? ははっきりした強みです。Snore Timeline は2人の寝ている人を区別できないので、誰のいびきかは耳で聞き分けることになります。

    スコアと対策

    どちらのアプリも夜を採点します。Sleep Cycle のサイトによると、Sleep Score は睡眠時間、睡眠ステージ、中断を測ります。Snore Timeline の睡眠スコアは0〜100で、いびきと呼吸の乱れは減点になります。

    どちらのアプリも、寝る前にしたことを記録できます。Sleep Cycle の掲載情報は、カフェイン、ストレス、運動が休息にどう影響するかを見るための睡眠メモを紹介しており、ヘルプセンターでは睡眠メモは Premium です。Snore Timeline には CPAP、マウスガード、鼻腔拡張テープ、横向きで就寝など23の組み込み睡眠要因があり、自分で追加することもできます。記録した夜が5夜になり、タグ付きが2夜以上、タグなしが2夜以上そろうと、アプリがタグ付きの夜とタグなしの夜を比べて、効果のあったものを順位付けします。手順は対策を試すガイドで説明しています。

    睡眠ステージ

    どちらのアプリもスマートフォンから睡眠ステージを推定します。Sleep Cycle のヘルプセンターによると、主に呼吸のパターンから覚醒、浅い睡眠、深い睡眠、REM を推定します。Snore Timeline は15分のベースラインを待ち、呼吸の規則性から同じ4つのステージを推定します。ウェアラブルも Apple ヘルスも必要ありません。夜間サマリーでは、いびきのグラフを音量と1分あたりのいびきで切り替えられ、その下に睡眠ステージの帯が表示されるので、いびきが浅い睡眠、深い睡眠、レム睡眠のどこに集中しているかがわかります。ハイプノグラムをタップすると、いびきのグラフの同じ時刻にマークが付きます。Apple Watch、Oura、Garmin、Whoop、Ultrahuman を着けていれば、そのステージも Apple ヘルスを通じて取り込まれ、ソースごとのタイムラインが分かれたまま残るので、並べて比べられます。

    医療機関のやり方は違います。NHLBI によると、臨床の睡眠検査では目の動きと脳の活動を記録するセンサーでステージを分類し、1サイクルは80〜100分で、1晩に4〜6回繰り返されます。どちらのアプリのステージも推定値として扱ってください。

    呼吸の一時停止と寝言

    呼吸の乱れの印が付くには、3つのことが順に起きる必要があります。まず1分以上の聞き取れる呼吸。次に10秒以上の無音。そして大きないびき、あえぎ、息など、その無音を破る音です。印はそれぞれ前後の音声とともにタイムラインに載ります。マイクが呼吸を聞き取れるよう、スマートフォンは頭から30〜60cmのところに置いてください。ルールの全体は呼吸の乱れのガイドで説明しています。

    Sleep Cycle のサイトによると、アプリは夜の間の呼吸を記録します。ヘルプセンターは iOS での呼吸数を Premium に入れており、Premium の呼吸の乱れのデータにも触れています。これには、音によるトラッキングが動くよう iPhone からセッションを始める必要があります。どちらのアプリの呼吸データも診断ではありません。

    いびきや一時停止は軽視できないこともあります。Sleep Foundation は、いびきを閉塞性睡眠時無呼吸の最もよくある症状の1つとしたうえで、いびきをかく人が全員そうだとは限らないと付け加えています。日中の眠気やあえぎなどのサインとともに、いびきが週に3回以上ある場合は医師に相談するよう勧めています。アプリの印は、その受診に持っていく材料です。

    寝言

    どちらのアプリも寝言を捉えます。Sleep Cycle には寝言レコーダーがあり、クリップを人に聞かせて楽しむものとして紹介しています。Snore Timeline は寝言をタイムラインに表示するのでクリップを1つずつ再生でき、オプションの大きな音のトリガーを使えば、分類器が見逃すささやき声やつぶやきも拾えます。

    Apple Watch、Android、エクスポート

    Apple Watch

    Sleep Cycle には、単独で夜を記録できる Apple Watch アプリがあります。ヘルプセンターによると、ウォッチのセッションはウォッチの加速度センサーで動きを記録するので、いびきは検出できず、いびきを記録するには iPhone でセッションを始めます。サイトではウォッチとの連携を Premium としており、ヘルプセンターの Premium の一覧には、Apple Watch 8 または Ultra での体温、ウォッチでの自動開始、心拍数の記録も入っています。

    Snore Timeline の Apple Watch 対応では、心拍数、HRV、呼吸数、SpO2、手首の体温が夜のデータに加わり、いびきをかいたときやアラームが鳴るときにウォッチが手首をタップします。付属の Watch アプリは録音中の心拍数と HRV をリアルタイムで表示し、録音を止めることもできます（始めるのは iPhone です）。Apple ヘルスを通じて、Apple Watch、Oura、Whoop、Garmin、Ultrahuman のデータを取り込みます。どれも睡眠スコア、回復スコア、ハイプノグラムに反映され、料金はかかりません。

    Android

    どちらのアプリも Google Play にあります。Sleep Cycle の掲載情報では、216K 件のレビューで評価は4.4 で、Wear OS への対応と Google Fit との連携があります。Snore Timeline は Android でも同じ検出、タイムライン、呼吸の印、エクスポートを備え、Health Connect にデータを書き込みます。Android ではウォッチには対応していません。

    エクスポート

    Snore Timeline は CSV のレポート（夜間サマリーとエピソードごとの詳細）、エピソードの音声クリップ、夜全体の音声を1回で書き出します。iPhone では「ファイル」App に、Android では「ダウンロード」に保存されます。Sleep Cycle のヘルプセンターは、データベースを CSV ファイルに書き出す方法を説明しており、録音はまとめて書き出せず、1件ずつ開いて自分に共有するとしています。App Store の掲載情報はデータのエクスポートを Premium のツールに挙げていますが、ヘルプセンターはデータベースのエクスポートを無料プランに入れています。

    どちらを選ぶか

    Sleep Cycle を選ぶなら

    • アラームがいちばんの目的の場合。Sleep Cycle のスマートアラームは無料で、時間枠を10〜30分の間で設定でき、Premium では多くのアラーム音が使えます。
    • 寝付くための助けが欲しい場合。掲載情報には、睡眠用の物語、サウンドスケープ、ガイド付き瞑想、睡眠プログラム、Luma という AI 睡眠コーチが含まれています。
    • 2人ともいびきをかき、どちらのいびきかをアプリに教えてほしい場合。Who's Snoring? がそれを行います（Premium）。
    • Wear OS のウォッチを着けている場合。Snore Timeline は Android ではウォッチに対応していません。
    • 長い実績を重視する場合。Sleep Cycle は2009年から App Store にあり、30K 件の評価とエディターのおすすめのバッジがあります。Snore Timeline の登場は2025年9月で、私が外部資金もマーケティング予算もなくひとりで開発しているため、214件の評価はずっと短い期間のものです。

    Snore Timeline を選ぶなら

    • サブスクリプションも購入もなしで、すべてのいびきを聞き、どの瞬間も再生したい場合。Sleep Cycle では、いびきの検出と音の検出は Premium です [13]。
    • お金を払わずに対策を試したい場合。Snore Timeline は23の組み込み睡眠要因と自分で作った要因について効果のあったものを順位付けします。Sleep Cycle の睡眠メモは Premium です [13]。
    • 印の付いた呼吸の一時停止を、無料で医師に聞かせたい場合。Sleep Cycle の呼吸の乱れのデータは Premium です [12]。
    • AirPods を着けたまま眠り、それで録音したい場合。Sleep Cycle のヘルプセンターは Bluetooth 機器の接続を切るよう案内しています [14]。
    • Apple Watch を着けていて、いびきナッジ、アラームのタップ、心拍数と HRV のリアルタイム表示を無料で使いたい場合。Sleep Cycle のウォッチとの連携は Premium で [3]、Watch のセッションではいびきを検出しません [15]。
    • CSV ファイル、エピソードのクリップ、夜全体の音声を1回で書き出したい場合。Sleep Cycle は録音を1件ずつ共有します [16]。
    • "Data Not Collected" のラベルとアカウント不要であることを重視する場合。

    ほかのいびきアプリが何に料金をかけているかは、無料のいびきアプリがそれぞれ有料にしている機能やSnore Timeline と SnoreLab の比較をご覧ください。

    医療に関する注意

    Snore Timeline は音声を分析します。医療機器ではなく、睡眠時無呼吸症候群やその他の疾患を診断するものでもありません。呼吸の一時停止が疑われる場合は、録音を医師に見せてください。

    よくある質問

    Sleep Cycle は無料でいびきを録音できますか？

    できません。ヘルプセンターは、いびきの検出を音の検出や Who's Snoring? とともに Premium に入れており、無料プランにはスマートアラーム、睡眠分析、毎晩の睡眠グラフが含まれます。App Store の掲載情報とウェブサイトは、プランを明示せずにいびきの記録に触れています。

    Snore Timeline は、すべての機能込みで一晩中いびきを録音・検出します。サブスクリプションも App 内課金もありません。

    Sleep Cycle はデータを収集しますか？

    はい。2026年9月27日に申告された App Store のラベルによるとそうです。Identifiers を Data Used to Track You に、Health & Fitness、Purchases、Location、Contact Info、Identifiers、Usage Data、Diagnostics を Data Linked to You に挙げています。Audio Data は挙げられていません。プライバシー通知によると、健康データは初期設定ではデバイスにとどまり、同意すればオンラインバックアップ、仮名化した製品研究、集計レポート、研究に使われることがあります。

    Snore Timeline のラベルは "Data Not Collected" です。アカウントも、サーバーも、分析 SDK もありません。

    Snore Timeline にスマートアラームはありますか？

    あります。スマートアラームは15分、30分、45分の時間枠の中で、アプリのリアルタイムの睡眠ステージ推定とあなたの体動や音から浅い睡眠だとわかったときに鳴ります。浅い瞬間が来なければ、設定した時刻に鳴ります。「睡眠インサイト」をオンにしておく必要があります。Apple Watch では、音の代わりに手首のタップで起こせます。

    夜全体のタイムラインを表示するのはどちらのアプリですか？

    Snore Timeline は、検出したいびき、あえぎ、咳、寝言のクリップ、呼吸の印をすべてタイムラインに載せます。タイムラインは1秒単位の細部から1時間単位の全体までズームでき、どの位置をタップしても音声が聞けます。Sleep Cycle は睡眠ステージ付きの毎晩の睡眠グラフを表示し、夜間の音を再生できます。サイトと App Store の掲載情報には、音ごとのタイムラインの説明はありません。

    どちらかのアプリで睡眠時無呼吸を診断できますか？

    できません。Snore Timeline は医療機器ではなく、睡眠時無呼吸症候群を診断するものでもありません。聞き取れる呼吸のあとの10秒以上の無音に印を付けるので、それを医師に聞かせることができます。Sleep Cycle の App Store の掲載情報は、いびきと咳の記録を "for wellness"（ウェルネスのため）と説明しており、睡眠時無呼吸を診断できるとはしていません。

    医師は睡眠検査で睡眠時無呼吸を確定または除外します。Sleep Foundation は、いびきは閉塞性睡眠時無呼吸のよくある症状であり、いびきをかく人が全員そうだとは限らないと述べています。
