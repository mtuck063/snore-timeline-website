データを収集するいびきアプリはどれ？

著者 Menelik Tucker · 更新日 2026年9月28日

結論

2026年9月27日の App Store での申告では、いびき・睡眠アプリ14本のうち4本が「データの収集なし」（Data Not Collected）と表示しています。Snore Timeline、AutoSnore、SnoreClock、Somnio+ です。14本の中で、このラベルがあり、しかも購入項目がまったくないのは Snore Timeline だけです。SnoreLab、Sleep Cycle、Pillow、ShutEye、BetterSleep、SleepScore、Snollo、Snore Control は、ユーザに関連付けられたデータを申告しています。そのうち SnoreLab、Sleep Cycle、ShutEye、BetterSleep は、ユーザのトラッキングに使用されるデータも申告しています。ラベルは開発元が自分で書くものなので、インストールする日に掲載情報をもう一度確認してください。

要点

  • 14本のうち4本が「データの収集なし」と申告しています。Snore Timeline、AutoSnore、SnoreClock、Somnio+ です。
  • Snore Timeline は、14本の中で「データの収集なし」と申告し、かつ購入項目がない唯一のアプリです。AutoSnore は買い切りで $4.99、SnoreClock は買い切りで $9.99、Somnio+ は週額と年額のサブスクリプションを販売しています。
  • 8本がユーザに関連付けられたデータを申告し、そのうち4本は「ユーザのトラッキングに使用されるデータ」も申告しています。
  • 5本がオーディオデータを申告しています。SnoreLab と Snollo はユーザに関連付けられたデータとして挙げています。ShutEye、Koala Nap、Snore Recorder - Sleep Monitor は関連付けられないものとして挙げています。
  • Apple によると、これらのラベルは開発元の自己申告で、アプリをアップデートしなくてもいつでも変更できます。
  • データを収集する10本のプライバシーポリシー：データを金銭で販売すると書いているものはありません。1本は、広告ネットワークの利用がカリフォルニア州法上の販売または共有にあたるとしています。4本は個人データの販売にまったく触れていません。「データの収集なし」の4本は、この調査の対象外です。
この記事の内容

    App Store のプライバシーラベルとは

    App Store のすべてのアプリの掲載情報には「アプリのプライバシー」セクションがあります。Apple はこれをプライバシー情報と呼び、多くの人はプライバシー栄養ラベルと呼んでいます。開発元が Apple からの質問に答えて記入し、App Store がその回答を最大3つの枠に変換します [1]。

    3つの区分

    • ユーザのトラッキングに使用されるデータ（Data Used to Track You）。広告のために、ほかの会社のアプリ、ウェブサイト、オフラインの情報源から得たデータと組み合わせるデータ、またはデータブローカーに渡すデータ [2]。
    • ユーザに関連付けられたデータ（Data Linked to You）。アカウント、デバイス、その他の情報を通じて、ユーザに関連付けられたデータ [1]。
    • ユーザに関連付けられないデータ（Data Not Linked to You）。開発元がユーザー ID などの識別子を取り除いたうえで収集するデータ [2]。

    開発元がどの区分にも何も申告しない場合、掲載情報には代わりに1つの枠だけが表示されます。データの収集なし（Data Not Collected）という見出しと、「デベロッパはこのアプリからデータを収集しません。」という一文です。

    Apple にとっての「トラッキング」の意味

    Apple の定義は狭いものです。アプリがほかの企業のデータと混ぜずに自社内で保持する分析データはトラッキングに含まれません [1]。そのため、ユーザに関連付けられたデータを長々と申告しながら、トラッキングの枠が表示されないアプリもありえます。Snore Timeline は自社でも外部の業者経由でも分析データを一切収集しないので、ラベルに申告するものがありません。

    「データの収集なし」と申告しているアプリ

    14本のうち4本のラベルに「データの収集なし」の枠が表示されています。4本は料金の取り方が異なり、その違いが Snore Timeline をほかと分けるポイントです。

    Snore Timeline

    Snore Timeline の掲載情報では、ダウンロードは無料でアプリ内購入はなく、評価は 214件で4.9です [4]。14本の中で、ラベルが空で、しかも購入項目がまったくないのはこのアプリだけです。SnoreLab の57,000件に比べて評価の件数が少ないのには理由があります。Snore Timeline が App Store に登場したのは2025年9月で、SnoreLab は2012年からあり、私は外部資金もマーケティング予算もなく、ひとりで開発しています。タイムラインにはいびき、寝言、あえぎ、咳、呼吸の一時停止の可能性にラベルが付き、睡眠ステージはウェアラブルなしでスマートフォンの音声だけから推定し、一晩分の録音音声、再生、エクスポートも無料です。念のため明記しておくと、これは私のアプリです。

    AutoSnore

    AutoSnore は最初に $4.99 かかり、アプリ内購入はありません [5]。掲載情報には AutoSleep を作ったチームのアプリだとあり、サブスクリプションも、隠れた追加のアプリ内購入もないとうたっています。

    SnoreClock

    SnoreClock は $9.99 の買い切りで、アプリ内購入はありません [6]。掲載情報によると、最長11時間録音でき、いびきと並べて話し声、ささやき声、咳に印を付けます。

    Somnio+

    Somnio+ はダウンロード無料で、$4.99 と $9.99 の週額サブスクリプション、$14.99 と $29.99 の年額サブスクリプションを販売しています [7]。掲載情報によると、長い無音の区間を呼吸の一時停止の可能性として印を付け、医療機器ではないと明記しています。

    ユーザに関連付けられたデータを申告しているアプリ

    8本のアプリが、ユーザに関連付けられたデータを申告しています。

    SnoreLab

    ラベルによると SnoreLab が保有するあなたの情報。あなたの身元に関連付け：メールアドレス、睡眠と健康の測定値、声や音の録音、サポートに送ったメッセージ、そしてそれらの記録をあなたに結び付けるユーザー ID。「睡眠と健康の測定値」は、字面から受ける印象より多くを含みます。SnoreLab のポリシーは、一晩を記録すると自動的に収集する睡眠データとして、呼吸数、呼吸の乱れ、睡眠ステージ、体の動きを挙げています。さらに、あなたが入力する性別、年齢、体重、身長と、そこから算出する BMI も加わり、ポリシーはこれらを健康データとして扱っています [11]。同じポリシーでは、SnoreLab がこのデータを使ってアプリに表示する内容をあなた向けに調整すること（オプトインした場合は、第三者の製品のおすすめやパートナーのプロモーションも含む）や、いびきが性別や BMI によってどう変わるかといった研究を行うことが認められており、匿名化された結果はアプリや報道機関を通じて公表されます。データはアカウントがある間と、アカウントを削除するかサブスクリプションを解約してから12か月間保持され、匿名化されたデータは無期限に保持されます。また、会社が売却された場合、あなたの個人データはおそらく買収先に渡るとしています [11]。あなたの身元に関連付けられない：デバイス ID、タップや表示した画面などアプリの使い方、クラッシュログ。

    ポリシーによる、データのほかの受け取り先。SnoreLab のラベルは Usage Data をユーザのトラッキングに使用するものとして申告しています。ポリシーはその用途に AppsFlyer を挙げ、SnoreLab が送るものとして、ユーザー ID、デバイスのデータ、購入、国、広告キャンペーンのデータ、そしてあなたの性別、年齢、体重、身長を列挙しています。これにより SnoreLab と第三者が “track your activity across apps and websites”（アプリやウェブサイトをまたいであなたの行動を追跡）できるとしています [11]。AppsFlyer はアトリビューションの仲介業者で、これについてはトラッキングの仕組みで説明します。毎晩の睡眠の測定値は AppsFlyer に送るものの一覧に入っていません。Google は Firebase を通じてメールアドレス、ユーザー ID、デバイスのデータ、属性情報、BMI を [26]、BigQuery を通じてユーザー ID を [29]、Google フォームを通じて利用者の声を受け取ります。Amazon の AWS [30] は、検出アルゴリズムの開発を含む研究のために、ユーザー ID、属性情報、デバイスのデータ、ヘルスケアのデータを受け取ります。SnoreLab のメールと通知を送る Customer.io も、メールアドレスと属性情報を受け取ります。ポリシーによると、SnoreLab が録音を収集するのは、クラウドバックアップに登録した場合か研究への参加を選んだ場合だけです。

    Sleep Cycle

    ラベルによると Sleep Cycle が保有するあなたの情報。あなたの身元に関連付け：名前とメールアドレス、健康の測定値、購入履歴、おおよその位置情報、ユーザー ID とデバイス ID、アプリの使い方、クラッシュログ。ラベルは、おおよその位置情報、名前、メールアドレス、両方の ID を、開発元自身の広告またはマーケティングの用途にも挙げています。声や音の録音は申告していません。Sleep Cycle のポリシーによると、健康データは初期設定ではデバイスにとどまり、あなたが同意しない限り会社はアクセスできません [12]。オプトインすると、それが4つの点で変わります。バックアップをオンにすると、アプリ内のすべてのデータが Google Cloud 上の Sleep Cycle のサーバーに送られ、同意を取り消すまで、そしてサブスクリプション終了後最長1年間保存されます。アプリの改善への協力に同意すると、健康データは仮名化されて、Amazon Web Services 上で Amplitude が運用する製品開発の環境に送られ、同意を取り消すまで、または収集から最長3年間の、いずれか長いほうの期間保持されます。インサイトの共有に同意すると、Sleep Cycle は健康データを含むあなたのデータを、集計または匿名化した形に限って、公開レポート、パートナー、登録者に見せるコミュニティの基準値に使うことがあり、同意を取り消したあとも、すでに収集したデータを仮名化して統計や科学の目的で保持することがあります。研究に参加すると、データは研究者に渡り、その後は研究者が管理します。

    ポリシーによる、データのほかの受け取り先。Sleep Cycle は、ID がほかの会社のアプリやウェブサイトをまたいだユーザのトラッキングに使用されると申告していますが、ポリシーは広告ネットワークの名前を挙げていません [12]。挙げているのは、Google（任意のサーバーバックアップをホストする Google Cloud）、Amazon（AWS）、Sinch（Mailgun [33]）、CleverTap（Leanplum [34]）と、Amplitude、Zendesk、Fivetran です。

    Pillow

    ラベルによると Pillow が保有するあなたの情報。あなたの身元に関連付けられるのは3項目（デバイス ID、アプリの使い方、クラッシュログ）です。購入履歴、おおよその位置情報、サポートに送ったメッセージ、ユーザー ID は関連付けられないものとして申告されており、トラッキングの枠はありません。声や音の録音は申告していません。

    ポリシーによる、データのほかの受け取り先。Pillow のポリシーは、Adjust を使って仮名化したデバイス ID を Meta および Google と共有していると明記しています [13]。OpenAI にもデータが渡ります。ポリシーによると、ChatGPT Ads のために、インストール、サブスクリプションのイベント、購入金額が Adjust 経由で OpenAI に送られます。Adjust は AppLovin の傘下で [32]、広告の成果を計測する仲介業者です（トラッキングの仕組みを参照）。ポリシーは Meta のネットワークとして Facebook、Instagram、Audience Network を挙げ、Google 広告の名前も挙げ、さらに Apple（iCloud と CloudKit [35]）、Mixpanel、RevenueCat、Sentry、Statsig、Intercom、MailerLite を挙げています。睡眠トラッキングと音声の分析はデバイス上で行われるとしています。

    ShutEye

    ラベルによると ShutEye が保有するあなたの情報。あなたの身元に関連付けられるのはユーザー ID とデバイス ID だけで、どちらも分析用として申告されています。健康の測定値、声や音の録音、アプリの使い方、クラッシュログ、起動時間などのパフォーマンスデータは、すべて関連付けられないものとして申告されています。ShutEye の開発元 Enerjoy は、ほかのアプリと合わせて1つのポリシーでカバーしています。そのポリシーによると、心拍数、睡眠、呼吸、血中酸素などのヘルスケアの健康データは、あなたが共有を選んだ場合にだけ収集され、あなた向けに個人化したプランを作るために使われます [15]。Enerjoy は健康データを広告パートナーと共有せず、健康とフィットネスのデータを広告、マーケティング、データマイニングに使わないとしています。オプトインすれば、睡眠データを受け取れるパートナーが1社あります。IKEA とのコラボレーションに参加すると、ShutEye は活動の終了時に、睡眠時間や睡眠の質などの睡眠データをあなたの IKEA Family 会員情報と結び付けて IKEA に渡し、IKEA が商品をおすすめできるようにします。ポリシーに決まった保持期間はありません。個人情報は、合理的に必要な期間、事業上の必要がある間、または法律が求める期間の、いずれか長いほうの期間保持されます。

    ポリシーによる、データのほかの受け取り先。ShutEye のラベルは、ID がほかの会社のアプリやウェブサイトをまたいだユーザのトラッキングに使用されると申告しています。2026年版のポリシーは、デバイスをまたいだトラッキングによるものを含む興味・関心に基づく広告を説明し、広告の成果を計測する仲介業者の AppsFlyer の名前を挙げています（トラッキングの仕組みを参照）[15]。古いポリシーもあります。Enerjoy の2024年7月版のウェブサイトのポリシーには、同社が過去12か月に一部の個人情報を、法律上の意味で「販売」および「共有」した可能性があるとあります [16]。2026年版のポリシーはほかに、Google（Firebase と Google）、Meta（Facebook [31]）、OpenAI、そしてコラボレーションに参加したユーザーについては IKEA の名前を挙げています。録音には触れていません。

    BetterSleep

    ラベルによると BetterSleep が保有するあなたの情報。あなたの身元に関連付け：名前とメールアドレス、購入履歴、ユーザー ID とデバイス ID、アプリの使い方、サポートに送ったメッセージ、あなたが作成したそのほかのコンテンツ、クラッシュログ、ラベルに名前のないその他のデータ。あなたの身元に関連付けられない：正確な位置情報とパフォーマンスデータ。

    ポリシーによる、データのほかの受け取り先。BetterSleep は、購入、ID、使用状況データ、その他のデータがユーザのトラッキングに使用されると申告しています。14本の中で、これほど多く挙げているアプリはほかにありません。ポリシーによると、広告ネットワークの利用は、カリフォルニア州法のより広い定義のもとでは販売または共有にあたります [17]。オプトアウトのページは、Facebook カスタムオーディエンス、コンバージョン計測ピクセル、Google アナリティクスの名前を挙げています [18]。Facebook は Meta の傘下です。臨床サービスのための OpenLoop の名前も挙がっています。録音については、BetterSleep は録音から得たデータを保持し、録音そのものは保持しないとしています。

    SleepScore

    Snollo のプライバシーポリシー [20] は、あなたの権利についての節で、Snollo はクロスコンテキスト行動広告のためにあなたの個人データを販売または共有しないとしています。第三者のサービスについての節では、誰ともデータを販売する関係にないとしたうえで、Apple のサービス、Mixpanel、PostHog、TelemetryDeck、Sentry、RevenueCat、Ahrefs を挙げています。Mixpanel が受け取るのはイベント名とユーザー ID で、睡眠データ、音声、名前は決して受け取りません。マイクについては、保存されるのは分類結果と短いクリップだけで、保存先はあなた専用の iCloud だとしています。

    Snollo の2つのページ。2026年9月27日に確認。
    ページ表示されている日付記載内容
    snollo.com/privacy [20]発効日：2026年5月27日プロフィールの記録は “are technically readable by Snollo through the CloudKit Dashboard.”（技術的には CloudKit Dashboard を通じて Snollo が読み取れる）
    snollo.com/privacy-first [21]最終確認：2026年4月“There is nothing to breach, sell, or subpoena.”（漏えいや販売、提出命令の対象になるものは何もありません）

    Koala Nap

    App Store の掲載情報にあるポリシーのリンクを開くと、koalanap.com/privacy-policy [22] が表示されます。私が確認した日には、このページには Privacy Policy という見出しだけがあり、本文はありませんでした。ブラウザで開いても、テキストとして取得しても同じでした。koalanap.com からほかのポリシー文書へのリンクもないため、引用できる開発元のポリシーの文章はありませんでした。Koala Nap が何を保有し、何を共有するかは、App Store のラベルからしかわかりません。

    Snore Control

    Snore Control のプライバシーポリシー [23] は、アプリをフリーミアムのアプリであり広告付きのアプリでもあると説明しています。AdMob、Firebase Analytics、Firebase Crashlytics の名前を挙げています。個人データ全般の販売には触れていませんが、ヘルスケアについての段落では、Snore Control はあなたの健康データを広告プラットフォーム、アフィリエイトネットワーク、データブローカー、情報再販業者に販売せず、健康データが外部のサーバーに送られることもないとしています。音声や録音には触れていません。

    Snore Recorder - Sleep Monitor

    App Store の掲載情報にあるポリシーのリンクを開くと、“Privacy Policy - Sleep Monitor: Snoring Tracker” という題の Google ドキュメント [24] が表示されます。販売には触れていません。分析のプロバイダとして Firebase の名前を挙げています。データの転送についての節では、開発元が個人データを含むデータをアゼルバイジャン共和国に移し、そこで処理するとしています。音声、録音、健康データには触れていません。

    プライバシーポリシーを自分で確認する方法

    ポリシーは変わるので、インストールする日に適用されているものを読んでください。アプリの App Store の掲載情報を開き、開発元のプライバシーポリシーのリンクをタップします。ページ内で “sell”、“share”、“third”、“advertis” を検索し、次に “audio” や “recording” を検索します。冒頭の日付を確認してください。ページに日付が複数ある場合や、リンク先のページが空の場合は、開発元に連絡して、どの版が適用されるのかを尋ねてください。

    ラベルからわからないこと

    プライバシーラベルは申告です。Apple はラベルを開発元による自己申告と説明し [2]、その正確さを保つ責任は開発元にあるとしています [1]。開発元はアプリのアップデートを出さなくても、いつでもラベルを変更できます。

    研究者たちは、ラベルをアプリのコードと突き合わせて検証しています。2023年の USENIX Security の論文は、iOS アプリ5,102本のプライバシーラベルとアプリのバイナリを分析し、ツールが見つけたデータの流れとラベルが一致しない事例を報告しました [3]。この研究はこのページのアプリを調べたものではありません。それでも、ラベルは出発点にすぎないこと、そして一晩分の音声をアプリに預ける前に開発元のプライバシーポリシーを読む価値があることを示しています。

    20秒でできるラベルの確認方法

    1. App Store アプリでアプリのページを開きます。
    2. アプリのプライバシーまでスクロールします。枠に区分とカテゴリが表示されます。
    3. アプリのプライバシーの見出しをタップすると、データの種類ごとに、開発元が示した用途が表示されます。
    4. データの種類について説明が必要なら、同じ画面のプライバシーポリシーのリンクをタップします。

    決める当日に確認してください。開発元はアップデートを出さなくても回答を変更できるので、このページのラベルは、ページ上部に示した確認日時点のもので、それ以降のことは示していません。

    Snore Timeline のラベルが空である理由

    Snore Timeline が「データの収集なし」と申告しているのは、アプリから私に送るものが何もないからです。登録するアカウントはありません。独自のサーバーも、分析 SDK も、サードパーティのトラッカーもありません。何も販売していないので、アプリ内購入も、記録する購入履歴もありません。

    音声の分析はスマートフォン上で行われます。録音、エピソードのデータ、睡眠ステージの推定はアプリのストレージにとどまり、その上限は1〜8GBの間で設定できます（ストレージと音声品質を参照）。自分でエクスポートしない限り、何もスマートフォンの外には出ません。CSV のレポート、エピソードのクリップ、一晩分の録音音声は「ファイル」アプリに書き出され、そこから医師や好きな相手に送れます（エクスポートと共有を参照）。ポリシーの全文は snoretimeline.com/privacy にあります。

    ラベルが空であることには代償もあります。アカウントがないので、クラウドへのバックアップもデバイス間の同期もありません。アプリを削除すると、先にエクスポートしていない限り、録音も一緒に消えます。

    機能、価格、ラベルの一対一の比較は、Snore Timeline と SnoreLab、Snore Timeline と ShutEye、Snore Timeline と BetterSleep を見てください。より広い一覧は SnoreLab の代替アプリにあります。

    医療に関する注意

    Snore Timeline は音声を分析します。医療機器ではなく、睡眠時無呼吸症候群やその他の疾患を診断するものでもありません。呼吸の一時停止が疑われる場合は、録音を医師に見せてください。

    よくある質問

    いびきアプリは録音をアップロードしますか？

    プライバシーラベルだけではわかりません。ラベルに並ぶのは、開発元が収集すると申告したデータの種類です。データがどこに送られ、どこに保存されるかは書かれていません。

    私が確認したとき、14本のうち5本がオーディオデータを挙げていました。SnoreLab と Snollo はユーザに関連付けられたデータ、ShutEye、Koala Nap、Snore Recorder - Sleep Monitor はユーザに関連付けられないものとして挙げています。残りの9本はオーディオデータを申告していません。録音の行き先を知るには、掲載情報からリンクされている各開発元のプライバシーポリシーを読んでください。

    「データの収集なし」のラベルがあるいびきアプリはどれですか？

    米国の App Store で14本を確認したところ、「データの収集なし」と表示しているのは4本でした。Snore Timeline、AutoSnore、SnoreClock、Somnio+ です。

    4本の中で購入項目がまったくないのは Snore Timeline だけです。AutoSnore は買い切りで $4.99、SnoreClock は買い切りで $9.99、Somnio+ は週額と年額のサブスクリプションを販売しています。

    App Store のプライバシーラベルは Apple が検証していますか？

    Apple はこの情報を開発元による自己申告だと説明しており、開発者向けのページでは、回答を正確かつ最新に保つ責任は開発元にあるとしています。

    定義と質問は Apple が決めます。回答は開発元が用意し、アプリをアップデートしなくてもいつでも変更できます。

    サブスクリプションで、アプリが収集するものは変わりますか？

    購入（データの種類は購入履歴）をラベルに加えることがあります。

    私が確認したとき、Sleep Cycle、BetterSleep、SleepScore、Snollo は購入をユーザに関連付けられたデータとして申告し、BetterSleep は購入を「ユーザのトラッキングに使用されるデータ」にも挙げていました。Pillow は購入履歴をユーザに関連付けられないものとして挙げていました。例外は Somnio+ です。サブスクリプションを販売していながら、「データの収集なし」と申告しています。

    アプリのプライバシーラベルを自分で確認するには？

    App Store でアプリのページを開き、「アプリのプライバシー」までスクロールします。枠にカテゴリが表示されます。「アプリのプライバシー」の見出しをタップまたはクリックすると、詳細がすべて開きます。そこには、データの種類ごとに、アナリティクスやアプリの機能など開発元が示した用途が表示されます。

    インストールを決めた当日に確認してください。開発元はアップデートを出さなくてもいつでも回答を変更できるので、先月のラベルが今日のものと一致するとは限りません。

    いびきアプリはあなたのデータを販売していますか？

    ラベルでデータの収集を申告している10本のアプリのプライバシーポリシーを読みました。10本のうち、データを金銭で販売すると書いているものはありません。BetterSleep は、広告ネットワークの利用がカリフォルニア州法上の販売または共有にあたるとしています。Sleep Cycle、Koala Nap、Snore Control、Snore Recorder - Sleep Monitor は、個人データ全般の販売に触れていません。

    SnoreLab、Pillow、SleepScore、Snollo は、販売しないと書いています。ShutEye のアプリのポリシーには Enerjoy は販売しないとありますが、Enerjoy のウェブサイト向けの2024年版ポリシーには、一部のカテゴリを販売または共有した可能性があるとあります。ポリシーが示すのは意図です。アプリが何を送信しているかを示せるのは、通信のキャプチャだけです。
